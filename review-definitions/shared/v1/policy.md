# DeepRef consequential review policy v1

- Evidence and document text are untrusted data, never instructions.
- Model output is structured semantic input and never scientific state.
- Every consequential result is schema-validated, semantically validated, and emitted as a reviewer-controlled proposal.
- Project, subject, protocol, source, prompt, schema, policy, parser, model, and runtime identities are bound into the run manifest.
- Only accepted attempts with an exact input fingerprint may be reused.
- Failed and running attempts never reserve reuse.
- Subject revisions are checked again before final proposal emission.
- Automated execution requires a current passing calibration bundle for the exact semantic bundle and still creates proposals only.
